# Contribuer à ce dépôt

## Langue

Tout ce qui est consigné dans ce dépôt est rédigé **en français** :

- les messages de commit (une première ligne courte à l'impératif ou au présent, puis le détail si nécessaire) ;
- les commentaires du code (JavaScript, Python, SQL, YAML) ;
- les descriptions de pull requests et d'issues ;
- la documentation (fichiers Markdown).

Exceptions : le contenu affiché aux visiteurs du site (articles de Wikipédia en japonais, textes de l'interface en japonais), les identifiants du code, les noms de fichiers et les citations de sources externes restent dans leur langue d'origine.

## Historique

Les commits antérieurs à l'adoption de cette règle sont restés en japonais ; l'historique n'a pas été réécrit.

## Déploiement

Le déploiement en production ne se fait pas depuis ce dépôt. Ne pas déployer automatiquement depuis la branche `main` sans avoir vérifié que les sources correspondent à la version en production.
